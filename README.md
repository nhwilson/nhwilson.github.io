# SOC 105 OER Repository

Welcome! This repository forms the basis of my Open Educational Resource for SOC 105, which I teach at Stony Brook University.

These notes are written in [quarto](https://quarto.org/), and published with [github pages](https://pages.github.com/).

I think of these notes as a contribution to the public good, so feel free to fork the repository as you see fit (but in keeping with the license), and please attribute it to me. I would also appreciate it if you'd notify me of any changes you make. Feedback is always welcome: `nick [a] nhwilson [det] org`.
